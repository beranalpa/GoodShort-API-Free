## 💰 Apa yang Kamu Beli

**Layanan TypeScript teruji produksi** yang mengintegrasikan API resmi GoodShort — dengan terobosan ad-unlock bawaan.

- **Unlock berbasis iklan** — setiap episode terkunci/berbayar terbuka gratis lewat mekanisme iklan resmi. Tanpa pembayaran, tanpa trik yang perlu dirawat.
- **Hingga 1080p** — stream HLS multi-kualitas (540p, 720p, 1080p) diproxy untuk pemutaran mulus.
- **Tanpa biaya per-request** — satu-satunya biaya adalah server.
- **Siap dijual kembali / white-label** — server, key, dan harga kamu sendiri.

---

## ✨ Fitur Utama

- 🔓 **Full unlock via iklan** — episode terkunci terbuka otomatis, tanpa paywall di level API
- 🎞️ **HLS 1080p** — kualitas tertinggi di antara source services, multi-bitrate
- 📡 **API katalog lengkap** — home, feeds, detail, episode, batch load, pencarian, hot searches
- 🔄 **Proxy stream bawaan** — playlist & segment direlay, klien tidak pernah menyentuh CDN
- ⚡ **Caching pintar** — cache TTL, restart tidak memperlambat
- 🔑 **Sistem API key** — tier, rate limit, kuota harian

## ⚡ Mulai Cepat

```bash
npm install
cp .env.example .env    # sesuaikan
npm run build && npm start
```

Kebutuhan: Node.js ≥ 18, VPS Linux apa pun (RAM 512 MB cukup). Tidak perlu install database.
