## 💰 O Que Você Está Comprando

Um **serviço TypeScript testado em produção** que integra a API oficial da GoodShort — com o avanço de desbloqueio por anúncios embutido.

- **Desbloqueio por anúncios** — cada episódio bloqueado/pago abre grátis pelo mecanismo oficial de anúncios. Sem pagamentos, sem truques para manter.
- **Até 1080p** — streams HLS multi-qualidade (540p, 720p, 1080p) em proxy para reprodução fluida.
- **Sem custo por requisição** — seu único custo é o servidor.
- **Pronto para revender / white-label** — seu servidor, suas keys, seus preços.
