**واجهة ذاتية الاستضافة لمحتوى GoodShort — تكامل مع الواجهة الرسمية مع فتح عبر الإعلانات. كل حلقة مقفلة تفتح مجانًا، بجودة HLS حتى 1080p.**

**اشترِ مرة واحدة، واستضف إلى الأبد. كود TypeScript كامل، بدون رسوم ترخيص، بدون تبعيات خفية.**

واجهة **GoodShort streaming API** ذاتية الاستضافة — تكامل مع الواجهة الرسمية للدراما القصيرة: تصفح، ابحث، وشغّل كل حلقة مفتوحة عبر آلية فتح الإعلانات، بجودة حتى 1080p. خدمة المصدر المميزة بأعلى جودة فيديو وفتح كامل للحلقات.

## 💰 ماذا تشتري؟

**خدمة TypeScript مُختبَرة في الإنتاج** تدمج الواجهة الرسمية لـ GoodShort — مع اختراق فتح الإعلانات المدمج.

- **فتح عبر الإعلانات** — كل حلقة مقفلة/مدفوعة تفتح مجانًا عبر آلية الإعلانات الرسمية. بدون دفع، بدون حيل تحتاج صيانة.
- **حتى 1080p** — بث HLS متعدد الجودات (540p، 720p، 1080p) عبر وكيل لتشغيل سلس.
- **بدون رسوم لكل طلب** — تكلفتك الوحيدة هي الخادم.
- **جاهز لإعادة البيع / العلامة البيضاء** — خادمك، مفاتيحك، أسعارك.

## ✨ الميزات الرئيسية

- 🔓 **فتح كامل عبر الإعلانات** — الحلقات المقفلة تفتح تلقائيًا، بدون قيود على مستوى الواجهة
- 🎞️ **HLS 1080p** — أعلى جودة بين خدمات المصدر، متعدد معدلات البت
- 📡 **API كتالوج كامل** — رئيسية، خلاصات، تفاصيل، حلقات، تحميل دفعة، بحث، بحث ساخن
- 🔄 **وكيل بث مدمج** — قوائم التشغيل والمقاطع تُمرر، العملاء لا يلمسون CDN أبدًا
- ⚡ **كاش ذكي** — كاش TTL، إعادة التشغيل لا تبطئك
- 🔑 **نظام مفاتيح API** — فئات، حدود معدل، حصص يومية

## ⚡ البدء السريع

```bash
npm install
cp .env.example .env    # عدّل حسب الحاجة
npm run build && npm start
```

المتطلبات: Node.js ≥ 18، أي خادم Linux (ذاكرة 512 م.ب تكفي). لا حاجة لقاعدة بيانات.
